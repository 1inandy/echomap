# CLAUDE.md — EchoMap

**The parent `~/Downloads/CLAUDE.md` and `PRODUCT_SPEC.md` ("The Workbench" 3D portfolio) do NOT
apply to this repo.** Ignore its stack, aesthetic, and milestone rules here.

EchoMap: an experimental iPhone app that estimates the distance to the nearest large surface
using the phone's own speaker and microphone (chirp + matched filter), with haptic feedback for
blind and low-vision users.

- What and why: `echomap_mvp_production_spec.md`
- Exactly how (parameters, steps, checks): `ONE_SHOT_PLAN.md` — **wins where the two disagree.**
- Status, deviations and on-device to-dos: `STATUS.md`

## Hard rules
- **No raw audio leaves the device** except through the explicitly labelled Capture Lab /
  diagnostics export the user starts themselves. No network, no analytics, no accounts.
- **Never claim "path clear"** or guaranteed detection. Report "nearest surface", not
  "surface ahead", until on-device test H0 shows directionality.
- **Low-confidence readings are suppressed** and shown as "No reliable reading", which has its own
  haptic pattern. Silence only when scanning is stopped.
- **VoiceOver label (+ value/hint where useful) on every control.** Dynamic Type to AX5.
- Python `lab/` is the reference implementation. Swift `EchoCore` must match it on the golden
  fixtures in `fixtures/`. Change both together and regenerate fixtures.
- Never weaken a check to make it pass. Physical limitations become documented checks.

## Layout & commands
- `lab/` — Python reference (numpy/scipy/matplotlib only). Venv: `lab/.venv`.
  - Tests: `lab/.venv/bin/python -m pytest lab/tests -q`
  - Fixtures: `lab/.venv/bin/python lab/make_fixtures.py`
- `EchoCore/` — Swift DSP package (Accelerate only, no AVFoundation; builds on macOS).
  - Tests: `swift test --package-path EchoCore`
- `App/` — iOS app (SwiftUI, iOS 17+). Project generated by XcodeGen from `App/project.yml`.
  - `cd App && xcodegen generate`
  - `xcodebuild -project App/EchoMap.xcodeproj -scheme EchoMap -destination 'generic/platform=iOS Simulator' build`
- Bump `SignalConfig.algoVersion` (Swift) and `ALGO_VERSION` (Python) whenever the pipeline output changes.

## Conventions
- Branch per milestone (`m0-foundation`, `m1-echocore`, `m2-capture-lab`, `m3-scan`, `m4-experiments`), small commits.
- Swift app target uses Swift 5 language mode (real-time audio code); EchoCore is Swift 6.
- No allocation, locks (other than the unfair-lock handoff) or Swift concurrency on the audio thread.
